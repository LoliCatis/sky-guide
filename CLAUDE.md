# Правила для работы над сайтом

## Новости сайта — дописывать в каждом заметном PR

На сайте есть раздел «Новости» (журнал изменений). Если PR меняет то, что увидит игрок (новый раздел, гайд,
способ заработка, заметное улучшение или исправление), **в этом же PR допиши запись** в `server/news/entries.js`:

- новая запись — **первой** в массиве `NEWS`: `{ id: 'ГГГГ-ММ-ДД-слово', date: 'ГГГГ-ММ-ДД', kind: 'new' | 'better' | 'fix', title, items: [...] }`;
- мелочь того же дня — пунктом в уже существующую запись этого дня (id старых записей не менять: по ним гаснет точка «новое»);
- пиши для игрока, просто и по-русски: что изменилось и чем полезно. По-английски — только имена собственные
  (предметы, NPC, мэры, места). Без технических слов (PR, ветки, сервер, сборка, API);
- нельзя: ники владельца и его друзей, вещи только для владельца (панели, почта, хостинг), ИИ-советчик как возможность для гостей;
- текст сам проходит через подсказки по тексту (`textRefs` → `RefsProvider` + `Rich`), ничего отдельно делать не надо;
- проверка: `npm test` (`server/test/news.test.js` — порядок, id, запрещённые слова).

Внутренние правки (тесты, деплой, рефакторинг) в новости не пишем.

## Остальное

- Весь новый текст на сайте — через `RefsProvider` + `Rich` (`client/src/guides/Rich.jsx`), словарь — `textRefs` на сервере.
- Новая страница: `PAGES` и `LOAD` в `client/src/App.jsx` и её id в `GROUPS` в `client/src/components/BottomNav.jsx`.
- Ветки: PR в `develop`, затем `develop` → `main` после `npm test` и `npm run e2e`. Сайт обновляется из `main` сам.
