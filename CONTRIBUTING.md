# Как предложить изменение

Сайт: [sky-guide.ru](https://sky-guide.ru). Предложения принимаются через pull request.

## Порядок

1. Сделай fork этого репозитория (кнопка **Fork** вверху справа).
2. Запусти сайт у себя (см. ниже) и внеси изменение в отдельной ветке.
3. Проверь: `npm test` и `npm run e2e` должны проходить.
4. Открой pull request в ветку `main` этого репозитория. Опиши, что меняется и зачем, приложи скриншот, если меняется вид.

## Запуск без ключа Hypixel

```
npm install
node scripts/make-fixture.js   # тестовый профиль и цены в папке data/
npm run build
npm start                      # http://localhost:3000
```

С ключом: скопируй `.env.example` в `.env` и впиши `HYPIXEL_API_KEY` (берётся на https://developer.hypixel.net).
Для разработки с горячей перезагрузкой: `npm run dev` (http://localhost:5173).

## Что примут, а что нет

- Тексты на сайте — по-русски и просто; по-английски только имена собственные (предметы, NPC, мэры, места).
- Новый текст на сайте проходит через подсказки по тексту: `RefsProvider` + `Rich` (`client/src/guides/Rich.jsx`).
- Заметное для игрока изменение — добавь запись в `server/news/entries.js` (правила в `CLAUDE.md`).
- Не принимаются: новые зависимости без причины, сбор данных посетителей, внешние скрипты и трекеры,
  обфусцированный или минифицированный код, изменения в `deploy/`, `Dockerfile`, `docker-compose.yml`
  и в проверках безопасности без объяснения.
- Никаких ключей, паролей и `.env` в коммитах.

Каждый PR читается целиком перед слиянием.
