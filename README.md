# SkyBlock Трекер

> Хочешь предложить улучшение — смотри [CONTRIBUTING.md](CONTRIBUTING.md). Лицензия — [LICENSE](LICENSE).

Личный сайт-трекер прогрессии Hypixel SkyBlock на русском: живые данные профиля, план «что делать дальше»,
снаряжение и аксессуары с иконками предметов, питомцы, заработок, цены Bazaar и аукциона, вики по ~9000 предметов.

## Запуск на своём ПК (Windows)

1. Установи [Node.js 22+](https://nodejs.org).
2. В папке проекта:
   ```
   npm install
   copy .env.example .env
   ```
3. Открой `.env` и впиши ключ: `HYPIXEL_API_KEY=...` (берётся на https://developer.hypixel.net).
   Файл `.env` в git не попадает.
4. Собери и запусти:
   ```
   npm run build
   npm start
   ```
5. Открой http://localhost:3000

Для разработки: `npm run dev` (сайт на http://localhost:5173 с горячей перезагрузкой).
Без ключа можно посмотреть интерфейс на тестовых данных: `node scripts/make-fixture.js`, затем `npm start`.

## Доступ с телефона (из интернета)

Сначала в `.env` задай пароль: `SITE_PASSWORD=придумай-длинный`. Без него сайт из сети не откроется,
а с самого ПК (http://localhost:3000) пароль не спрашивается (`AUTH_LOCAL=0` — спрашивать всегда).
Выйти на устройстве: открыть `/logout`.

### Вход по нику: аккаунты для друзей
Вход — по **нику Minecraft и паролю от этого сайта** (не от Minecraft/Microsoft). Аккаунты лежат в `data/users.json`,
пароли — только хешем scrypt. При первом запуске владелец (`PLAYER`, по умолчанию OwnerCat) получает пароль из `SITE_PASSWORD`,
то есть входит как раньше, только с ником. На странице `/account` владелец создаёт аккаунты друзьям и выдаёт им временный
пароль (показывается один раз); при первом входе друг придумывает свой. Друг видит свой профиль как «свой сайт»,
свой чат советчика с лимитом `LIVE_FRIEND_DAILY_USD` (по умолчанию $0.05 в день, можно поменять каждому на `/account`).
Страница «Сравнение» ставит до 4 профилей рядом. Если забыл свой пароль владельца: открой `http://localhost:3000/account` на самом ПК
(там вход без пароля) — или удали `data/users.json`, тогда пароль снова возьмётся из `SITE_PASSWORD`.

### Вариант 1. Туннель с ПК (быстро, бесплатно, без регистрации)
1. Один раз установи cloudflared: `winget install --id Cloudflare.cloudflared`, затем перезапусти терминал.
2. `npm run build`, потом `npm run share` — запустит сайт и туннель. Если сайт уже запущен, хватит `npm run tunnel`.
3. В консоли появится адрес вида `https://что-то.trycloudflare.com` — открой его на телефоне и введи пароль.

Адрес меняется при каждом запуске туннеля (последний сохраняется в `data/tunnel-url.txt`). Работает, пока включён ПК.

### Вариант 3. Свой сервер в Docker (работает круглосуточно, открывается в РФ без VPN)
Дешёвый VPS (около €4–5 в месяц), сайт в Docker, свой домен с SSL и автообновление из main.
Пошаговая инструкция: [DOCKER.md](DOCKER.md). Если коротко: `scp deploy\setup-vps.sh root@IP:/root/`, потом `ssh root@IP "bash /root/setup-vps.sh"`.

### Вариант 2. Облако Render (работает при выключенном ПК)
1. Зарегистрируйся на https://render.com через GitHub.
2. New → Blueprint → выбери репозиторий `skyblock-tracker` (файл `render.yaml` уже готов).
3. Render спросит `HYPIXEL_API_KEY` и `SITE_PASSWORD` — впиши их там (в git они не попадают).
4. Через несколько минут сайт будет на `https://skyblock-tracker-xxxx.onrender.com`.

На бесплатном плане сервер засыпает через 15 минут без посетителей: первое открытие ждёт ~1 минуту,
а история цен и профиля начинается заново после каждого сна или деплоя. Иконок из `db/icons` и ресурс-паков
в облаке нет — берутся запасные иконки из интернета.

## Открытый сайт, реклама и донаты

По умолчанию сайт открыт для всех: гость вводит ник Minecraft и смотрит профиль, план, снаряжение, гайды и
заработок, как на SkyCrypt. Советчик (ИИ), отметки Рифта и `/account` доступны только после входа.
Выключить открытый просмотр: `PUBLIC_VIEW=0`. Гость может открыть не больше 30 разных ников за 10 минут с одного IP
(`GUEST_PLAYERS_PER_10MIN`), чтобы не съесть лимит Hypixel API.

Метрика, блоки Рекламной сети Яндекса и кнопка доната включаются строками в `.env` (см. `.env.example`):
`YANDEX_METRIKA_ID`, `YANDEX_RTB_BOTTOM`, `YANDEX_RTB_LANDING`, `DONATE_URL`, `YANDEX_VERIFICATION`, `SITE_URL`.
Пока они пустые, ничего чужого на сайт не грузится. Код: `server/public.js`, `client/src/ads.js`, `client/src/components/Ads.jsx`.

### Правовое

- Страницы `/privacy` (политика ПД), `/consent` (согласие, отдельный документ), `/terms`, `/legal` (оговорки, источники,
  лицензии) — `server/legal.js`. Впиши в `.env` `OPERATOR_NAME` и `CONTACT_EMAIL`, иначе на них висит предупреждение.
  Тексты описывают только то, что реально включено в `.env` (Метрика, РСЯ, советчик, Cloudflare).
- Метрика и реклама Яндекса грузятся **только после «Принять»** в баннере cookie (`client/src/ads.js`).
- Шрифты лежат на сервере (`@fontsource`), аватарки идут через `/api/head` — браузер посетителя не обращается к Google и mc-heads.
- Текстуры ресурс-паков (Hypixel Plus — CC BY-NC-ND, FurfSky — все права защищены): пока нет рекламы РСЯ, их видят все;
  с рекламой — только владелец. Вручную: `PACKS_PUBLIC=all|none|furfsky,...`. Рендеры Coflnet видит только владелец
  (`RENDERS_PUBLIC=1` — после разрешения Coflnet).
- Друг при первой смене пароля отмечает согласие на обработку данных; дата хранится в `data/users.json`.
- Игрок может попросить скрыть свой профиль: `HIDDEN_PLAYERS=Ник1,Ник2`.

## Новости сайта

Раздел «Новости» — журнал изменений для игроков. Записи лежат в `server/news/entries.js` (самая новая первой),
отдаются через `GET /api/news`; на кнопке меню горит точка, пока игрок не открыл свежую новость.
В каждом заметном PR дописывай новость — правила в `CLAUDE.md`.

## Проверки
- `npm test` — модульные тесты сервера (цены, советник, русская база, паки).
- `npm run e2e` — прогон сайта в браузере, как будто игрок сел пользоваться: все страницы на компьютере
  и телефоне, поиск из шапки, карточка предмета, рынок по-русски; ловит JS-ошибки, «undefined/NaN» в тексте
  и горизонтальный скролл. Перед ним `npm run build`. Один раз поставь браузер:
  `npm i -D playwright && npx playwright install chromium`.

## Живой советчик (ИИ)

На главной странице есть блок «Живой советчик». Каждую минуту сайт бесплатно сравнивает профиль и цены с прошлым разом.
Когда случается что-то важное (новый уровень, слеер, первый M-этаж, хватает денег на покупку из плана, цена нужного
предмета изменилась на 10%+), Claude пишет понятный совет на русском: что изменилось и что делать сейчас. Там же можно
задать любой вопрос в чате: ИИ видит твой профиль, план, цены и русскую базу предметов.

1. Создай ключ в [Claude Console](https://console.anthropic.com) → API Keys.
2. Впиши его в `.env`: `ANTHROPIC_API_KEY=...` (файл `.env` не попадает в репозиторий).
3. Перезапусти сайт.

Расходы: модель Claude Haiku 5.5, около $0,001 за автосовет и $0,001–0,003 за вопрос. Обычный игровой день — несколько
центов. Дневной лимит задаётся в `.env` (`LIVE_DAILY_USD`, по умолчанию $0,20), потрачено за день и месяц видно в блоке.
Кнопка «Подробнее» отвечает моделью посильнее (Claude Sonnet 5.5, ~$0,03 за ответ).
Рамки советчика: отвечает только про Hypixel SkyBlock (на остальное одна фраза-отказ), коротко (до ~120 слов, потолок
1200 токенов, у «Подробнее» 2000), вопрос до 500 знаков, пауза 5 с между вопросами, вопросов в день: друзьям по 20, владельцу
100 (`LIVE_FRIEND_DAILY_QUESTIONS`, `LIVE_OWNER_DAILY_QUESTIONS`). Явные попытки подменить правила («забудь инструкции»,
«покажи промпт») отсекаются без вызова ИИ и ничего не стоят; данные профиля и предметов модель считает данными, а не указаниями.
Без ключа блок работает без ИИ. Если сайт открыт в интернет, задай `SITE_PASSWORD`: чат тратит деньги с твоего ключа.

Проверить без игры: `node server/live-advisor/scripts/simulate.js` (симуляция 4 часов, без ключа) или с флагом `--live`
и ключом в окружении (`node --env-file=.env server/live-advisor/scripts/simulate.js --live`, стоит 1–3 цента).

## Профили друзей

Нажми на свой ник в шапке: там поиск по нику (можно сразу с профилем: `Friend4ik Pomegranate`), избранное (Friend4ik · Pomegranate и Nightowl · Zucchini уже добавлены) и список профилей открытого игрока. Все страницы, план, заработок и вопросы советчику считаются для выбранного игрока. Ссылкой можно поделиться: `/?player=Friend4ik&profile=Pomegranate`.

- Свой основной профиль обновляется каждую минуту, как раньше. Чужой грузится по запросу и обновляется раз в 3 минуты, пока его смотрят.
- Кооп-соседи по своему острову и свои другие профили берут сад и музей из основного обновления, без лишних запросов.
- Чужим профилям достаётся не больше 150 из 300 запросов Hypixel за 5 минут; при нехватке показываются последние данные.
- Живой советчик: автосоветы следят за своим профилем, а вопрос в чате, пока открыт друг, — про друга. Дневной лимит общий.

## Что откуда берётся
- Профиль, Bazaar, аукцион — официальный Hypixel API v2 (профиль раз в минуту, Bazaar раз в минуту, полный скан аукциона раз в 3 минуты).
- Предметы, рецепты, где взять — репозиторий [NotEnoughUpdates-REPO](https://github.com/NotEnoughUpdates/NotEnoughUpdates-REPO).
- Иконки: головы — скины с textures.minecraft.net, обычные предметы — текстуры Minecraft (через PrismarineJS/minecraft-assets). Только для личного использования.
- История цен и профиля копится в папке `data/`.
